# Трек: Apiary

Статус: **ЧЕРНОВИК**, 2026-09-23. Документ роадмапа: [`docs/drafts/apiary/minimal-roadmap.ru.md`](minimal-roadmap.ru.md) (черновик, стадии 0–6, учтены два независимых ревью). Дом дизайна: `curator-agent-runtime` (дизайн Apiary от 2026-09-08). Место в роадмапе: после этапов M4 и M7.

## Зачем

Один оркестратор должен вести пул локальных и удалённых агентских циклов. Каждый цикл работает на учётных данных своего владельца в выделенном рабочем пространстве проекта, а результаты проходят существующий путь ревью и интеграции.

## Как это связано с остальным

- Локальный запуск дочерних агентов становится первым бэкендом AgentHost. Он уже собирает запуски через модуль (M2, M3) с привязками сред исполнения (M4).
- AgentOffer публикует привязки сред исполнения, разрешённые сетевые профили и доступность (M4, M5, M7).
- Маршруты плейбуков становятся программой координатора (PB3); роли отображаются на роли назначений.
- Выбор агента даёт каждой машине личный допуск и предпочтения, а слой проекта остаётся переносимым между участниками (M4).

## Этапы

| Стадия | Что даёт | Нужно |
| --- | --- | --- |
| 0 | адаптер AgentHost/SessionDriver поверх сегодняшних `ProviderHost`/`RunOwner` | M3, M4 |
| имя | имя продукта Apiary на публичной поверхности; имена в протоколах не меняются | M3 |
| 1 | один удалённый исполнитель: допуск ключа, предложение, назначение, один мост, рабочее пространство на хосте проекта | стадия 0, M7 |
| 2 | надёжный доверенный пул: долговечный почтовый ящик, пробуждение без терминала, переподключение, отмена, аренды; маршруты плейбуков исполняет координатор | стадия 1, PB3 |
| 3–6 | ограниченные профили исполнения, несколько оркестраторов, внешние участники и собственная среда, распределённая автономия | по роадмапу Apiary |

## Репозиторий

`curator-agent-runtime`: роадмап Apiary, этот документ трека и поправка к authority wire ([`docs/drafts/apiary/authority-wire-amendment.ru.md`](authority-wire-amendment.ru.md)) лежат черновиками в `docs/drafts/apiary/`. Принятый снимок дизайна (`.spec/apiary-runtime-design.md`, `docs/apiary/`) и собранное из него интерактивное руководство не меняются, пока рецензированное принятие не перенесёт в них материал и не пересоберёт руководство.
